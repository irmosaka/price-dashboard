داشبورد قیمت لوازم خانگی 📊

یک داشبورد مدرن و قدرتمند برای مقایسه قیمت لوازم خانگی (تلویزیون، یخچال و لباسشویی) از دو فروشگاه بزرگ ایرانی: **دیجی‌کالا** و **ترب** با محوریت برندهای اسنوا و دوو


✨ ویژگی‌ها

- **رابط کاربری مدرن و تمام‌فارسی** (RTL + فونت وزیر)
- مقایسه همزمان قیمت‌ها از **دیجی‌کالا** و **ترب**
- فیلترهای پیشرفته (قیمت، برند، سایز، تکنولوژی، نوع و ...)
- تشخیص هوشمند برند و مشخصات از عنوان محصولات
- نمودارهای قیمت با Chart.js
- دسته‌بندی کامل لوازم خانگی:
  - تلویزیون
  - یخچال و فریزر (SBS، Twin، کمبی و ...)
  - ماشین لباسشویی
- جستجوی هوشمند
- به‌روزرسانی منظم داده‌ها
